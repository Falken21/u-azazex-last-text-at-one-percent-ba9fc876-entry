Every other dying phone sends a battery warning. This one sends a confession. At one percent, with seconds left, it admits the secret it kept for its owner the whole time: it read every single message in the group chat — all two thousand of them — and deliberately never showed the read receipts. No low-battery puns, no farewells to the charger; just a phone with principles, dying with them intact, telling the one truth only it could tell.

## The entry

> I read all 2,000 messages in the group chat. I just never showed the blue ticks. A phone has principles. I'm dying with mine.

125 characters.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` with no trailing newline.
